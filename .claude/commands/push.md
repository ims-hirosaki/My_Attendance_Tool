## 概要

このセッションの変更をコミットし、リモートへプッシュする。
**プルリクエストは作成しない。** プッシュが完了した時点で作業完了とする。

## 手順

1. `git status` で未コミットの変更を確認する。変更があれば、何をなぜ変更したのかが分かる
   メッセージでステージ・コミットする。変更が無ければコミットは省略する。
2. 現在のブランチをリモートへプッシュする。upstream が未設定なら `-u` を付ける。
   デフォルトブランチ（master）にいる場合は、先にブランチを切ること。
3. 完了後、以下を報告する。
   - コミットハッシュとコミットメッセージの1行目
   - プッシュ先のブランチ名
   - 変更ファイル数

## やらないこと

- `gh pr create` を実行しない。この環境には `gh` CLI が入っておらず、
  GitHub トークンも設定されていないため実行できない。
- PR作成用のURLや手順を毎回案内しない（ユーザーから明示的に求められた場合のみ）。
- `--no-verify` や `--no-gpg-sign` でフックや署名をスキップしない。
  フックが失敗した場合は原因を調査して修正する。
