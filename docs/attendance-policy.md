# 出勤アラート・職種別固定休憩（3.6.0）

## 導入時の設定

「打刻ツール → 設定」で次を保存します。

1. 出勤の丸め単位を60分にする。退勤の丸め単位は従来の値を維持する。
2. 「8時以外の出勤アラート」を有効にし、適用開始日を入力する。
3. 「休憩スライダーと休憩打刻ボタンを表示する」をオフにする。
4. 職種別休憩ルールを追加し、各行の職種と休憩分数を設定する。デフォルトを1件選択する。同じ職種の重複登録は不可。
5. 「短時間勤務の休憩アラート」を必要に応じて有効にする。

既存環境への追加だけでは、出勤アラートは有効にならず、休憩入力も非表示になりません。職種ごとの分数や開始日は設定画面で指定します。既存の保存済み休憩時間は変更しません。丸め設定の「今後の打刻のみ」を選ぶと過去の丸め値も変更しません。

## 出勤アラート

開始日以降の休日以外の出勤行について、丸め後の始業が8:00以外なら「8時以外の出勤打刻があります。」を黄色で表示します。出勤のみで退勤が未登録の行も対象です。60分丸めでは7:00は対象、7:01〜8:00は対象外、8:01は対象です。

従業員打刻履歴・アラート一覧・修正モーダルで表示し、一覧の「例外出勤」フィルターで絞り込めます。修正モーダルでは実打刻時刻を変更できます。未選択・未承認・却下は未対応のまま、承認済みだけグレーになります。却下後は打刻を修正して解消します。修正で始業が8:00になればアラートは消え、保存した承認ステータスは残ります。

## 固定休憩

職種IDに対応する固定休憩を退勤確認時の計算に使い、退勤確定時に保存します。職種未設定・対応ルールなしの場合はデフォルトを使い、「職種が未登録です。管理者にお伝えください。」を打刻画面に表示します。

短時間勤務アラートが有効で、固定休憩が拘束時間に応じた休憩マスタの自動判定値を上回る場合、実際の休憩分数への修正が必要です。0分も入力できます。未入力・固定値と同じ値・拘束時間を超える値・小数・負数では確定できません。修正後は残業・深夜休憩も更新された休憩時間で判定します。

管理画面の休憩アラート、および従来の「退勤時の休憩確認」は既存設定の基準を維持します。「短時間勤務の休憩アラート」をオフにしても、従来の休憩確認が有効なら基準との差について確認されます。
